# JobShield AI

JobShield AI analyzes job postings for recruitment fraud using machine learning
and rule-based checks.

| Link | Description |
|---|---|
| [Live app preview](https://jobshield-ai-7xy2.onrender.com/) | React + FastAPI application on Render |
| [Render service dashboard](https://dashboard.render.com/web/srv-dbvunjflk1mc73bu080g) | Manage service deployment and environment |
| [Deploy another instance](https://render.com/deploy?repo=https://github.com/balachandu187/jobfraud) | Create another React + FastAPI service |
| [GitHub Pages deployment status](https://github.com/balachandu187/jobfraud/actions/workflows/pages.yml) | Static landing-page deployment workflow |
| [Source code](https://github.com/balachandu187/jobfraud) | Browse this repository |

The live app runs on Render's free instance, which may sleep when idle and can
take a short time to wake up. Google sign-in also requires
`https://jobshield-ai-7xy2.onrender.com` to be listed under the Google OAuth
client's Authorized JavaScript origins. Never put OAuth secrets in this repository.

See [JobShieldAI/README.md](./JobShieldAI/README.md) for local setup, architecture,
and deployment details.
