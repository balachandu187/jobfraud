Cryptographic Security & System Architecture

JobShield AI enforces strict zero-trust standards. User authentication is authenticated with Google and PBKDF2 salting, while all scanning operations occur locally with immutable SQLite logging.

PBKDF2-HMAC-SHA256

Passwords are salted with 16 random bytes and hashed with 100,000 iterations of PBKDF2-SHA256. Stored credentials cannot be rainbow-tabled.

Tamper-Proof Bearer Tokens

API sessions use constant-time HMAC-SHA256 authenticated payloads with strict UTC timestamp expirations to prevent replay attacks.

Zero Third-Party Leaks

Candidate text and corporate disclosures run on local TF-IDF matrices and in-memory regex. No external APIs scrape or ingest your job postings.
